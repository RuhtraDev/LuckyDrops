## <a name="portugues"></a>🇧🇷 Português

### 📋 Sobre
Um rastreador de drops especiais do RuneScape para Alt1 Toolkit. Monitora automaticamente mensagens de drops de **qualquer fonte** no chat, incluindo anéis, espíritos de Seren e eventos especiais.

### ✨ Funcionalidades
- ✅ Detecta automaticamente mensagens de drops no chat
- 💎 Suporte para LOTD (Luck of the Dwarves)
- 👑 Suporte para HSR (Hazelmere's Signet Ring) - normal e duplicado
- ✨ Suporte para Seren Spirits
- 📦 Qualquer outro drop personalizável pelo usuário
- 📊 Histórico completo de todos os drops
- 📈 Totais por item com separação por fonte
- 📤 Exportação CSV
- 🔔 Integração com Discord Webhook
- 📝 **Frases 100% personalizáveis** - adaptável a qualquer mensagem do jogo

### 🎯 Tipos de drops detectados
| Fonte | Ícone | Exemplo |
|-------|-------|---------|
| LOTD | 💎 | Your Luck of the Dwarves shines brightly... |
| HSR Normal | 👑 | Your Hazelmere's signet ring shines brightly... |
| HSR Duplicado | 👑👑 | The power of Hazelmere blesses your drop... |
| Seren Spirit | ✨ | A golden beam shines over one of your items... |
| Personalizado | 📝 | Qualquer mensagem que você configurar |

### 🔧 Como instalar
1. Copie o link abaixo
2. No Alt1, clique em "Add App" (+)
3. Cole o link e confirme
   
alt1://addapp/https://ruhtradev.github.io/LuckyDrops/appconfig.json

Ou acesse diretamente no navegador Alt1:

https://ruhtradev.github.io/LuckyDrops/

### 🎯 Como usar
1. Abra o app com o RuneScape visível
2. Selecione o chat de loot
3. (Opcional) Configure frases personalizadas no menu Settings
4. Pronto! Os drops serão detectados automaticamente

### ⚙️ Configuração
- **Timestamps** devem estar ATIVADOS
- **Transparência** da interface em 0%
- **Filtro de chat** desligado

### 📝 Frases Personalizáveis
Você pode adicionar suas próprias frases para detectar qualquer tipo de drop:

Formato: Use (\d+) para quantidade, (.+) para nome do item

Exemplo: You receive (\d+) x (.+) from the chest

### 📝 Créditos
Baseado no [SerenTracker](https://github.com/ZeroGwafa/SerenTracker) e [ComponentCounter](https://github.com/ZeroGwafa/ComponentCounter) por **ZeroGwafa**

## <a name="english"></a>🇬🇧 English

### 📋 About
A special drop tracker for RuneScape Alt1 Toolkit. Automatically monitors drop messages from **any source** in chat, including rings, seren spirits, and special events.

### ✨ Features
- ✅ Automatically detects drop messages in chat
- 💎 LOTD (Luck of the Dwarves) support
- 👑 HSR (Hazelmere's Signet Ring) support - normal and double drops
- ✨ Seren Spirit support
- 📦 Any other drop customizable by the user
- 📊 Complete drop history
- 📈 Item totals with source separation
- 📤 CSV Export
- 🔔 Discord Webhook integration
- 📝 **100% customizable phrases** - adaptable to any game message

### 🎯 Detected drop types
| Source | Icon | Example |
|--------|------|---------|
| LOTD | 💎 | Your Luck of the Dwarves shines brightly... |
| HSR Normal | 👑 | Your Hazelmere's signet ring shines brightly... |
| HSR Double | 👑👑 | The power of Hazelmere blesses your drop... |
| Seren Spirit | ✨ | A golden beam shines over one of your items... |
| Custom | 📝 | Any message you configure |

### 🔧 Installation
1. Copy the link below
2. In Alt1, click "Add App" (+)
3. Paste the link and confirm
alt1://addapp/https://ruhtradev.github.io/LuckyDrops/appconfig.json

Or access directly in Alt1 browser:

https://ruhtradev.github.io/LuckyDrops/

### 🎯 How to use
1. Open the app with RuneScape visible
2. Select the loot chat
3. (Optional) Configure custom phrases in Settings menu
4. Done! Drops will be detected automatically

### ⚙️ Setup
- **Timestamps** must be ON
- **Interface transparency** at 0%
- **Chat filter** OFF

### 📝 Custom Phrases
You can add your own phrases to detect any type of drop:

Format: Use (\d+) for quantity, (.+) for item name

Example: You receive (\d+) x (.+) from the chest
